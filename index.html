A notebook word race for friends. Everyone gets the same letter. Fill every category before anyone else.

or join a friend

Quick rules

  • Each round shows one random letter. Write an answer that starts with it for every category.
  • The first player to submit ends the round for everyone, and all answers lock.
  • A correct answer that nobody else wrote scores 10 points.
  • Duplicates, wrong letters and answers not in our list score 0.
Full instructions

Every box must be filled before you can submit. A wrong answer can still be submitted, but it earns nothing.

Answers are checked against a fixed answer list for each category, not by guesswork. Real answers that are missing from the list score zero in this version.

If two or more players write the same answer (spelling and capital letters do not matter), nobody gets points for it.

After the last round the highest total wins. If players tie, a tiebreaker round decides it. Then everyone can vote on a rematch.
